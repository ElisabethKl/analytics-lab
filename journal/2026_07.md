## 30.07.

Git/GitHub
- Git speichert Datein, keine leeren Ordner (ggf mit .gitkeep arbeiten um Ordnerstruktur sauber im repository anzulegen)
- status -> add -> commit -> push ist der Grundworkflow
- SSH verbindet den Rechner sicher mit GitHub

Python-Umgebung
- Eine virtuelle Umgebung (.venv) gehört zu einem Projekt
- Sie enthält die Werkzeuge, die dieses Projekt braucht
- VS Code muss auf diese Umgebung zeigen

Jupyter
- Ein Notebook besteht aus Markdown- und Code-Zellen
- Ein Kernel führt den Python-Code aus
- Das Notebook kann unabhängig von anderen Projekten arbeiten
